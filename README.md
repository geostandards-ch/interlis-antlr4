# INTERLIS 2.4 ANTLR4 grammar

ANTLR4 grammar for parsing the INTERLIS 2.4 language.

This ANTLR4 grammar is based on the INTERLIS 2.4 specification published by eCH:

- https://www.ech.ch/fr/ech/ech-0031/2.1.0

The specification is also available in an AsciiDoc/HTML format:

- https://github.com/geostandards-ch/doc_refhb24

The original grammar is defined using a WSN-based notation. This repository contains an independent ANTLR4 adaptation which has been adjusted to comply with ANTLR4 grammar requirements.

## Compatibility

The grammar targets the INTERLIS 2.4 language specification.

Because the grammar has been adapted for ANTLR4, differences may exist compared with other INTERLIS grammar representations or implementations.

The generated parsers are intended for parsing INTERLIS 2.4 models and may not provide identical behavior to other INTERLIS tools in all edge cases.

## Prerequisites

Install `uv` by following the official installation instructions:

https://docs.astral.sh/uv/getting-started/installation/

## Installation

To create the project's virtual environment and install its dependencies:

```sh
uv sync
```

:::info
This step is optional: running any `uv run ...` command will automatically create the environment and install the required depencies if needed.
:::

## Configuration

The ANTLR version used by `antlr4-tools` is configured through the `.env` file:

```text
ANTLR4_TOOLS_ANTLR_VERSION=4.13.2
```

Run commands with the environment loaded:

```sh
uv run --env-file .env <command>
```

## Usage

To parse an input file, use the following command:

```bash
uv run --env-file .env antlr4-parse InterlisLexer.g4 InterlisParser.g4 <rule> input/<inputfile.extension> -<option>
```

### Options

- `-tree`: Display the parse tree.
- `-gui`: Display the parse tree in a graphical interface.
- `-tokens`: Display the tokens.
- `-diagnostics`: Display the errors

You can also parse an expression directly from the command line:

```sh
uv run --env-file .env antlr4-parse InterlisLexer.g4 InterlisParser.g4 <startRule> -tree
<input_expression>
^D
```

Generating a log with all the inconsistencies:

```sh
uv run --env-file .env antlr4-parse InterlisLexer.g4 InterlisParser.g4 <rule> input/<inputfile.extension> -diagnostics > errors.log 2>&1
```

## Generating a parser

The ANTLR4 grammar is target-language independent. This repository uses Python and `uv` as the development environment, but the grammar can be used to generate parsers for any ANTLR4-supported target, including Java, JavaScript, TypeScript, Go, Dart, C#, C++, Swift, PHP and others.

### Python

```sh
uv run --env-file .env antlr4 \
    -Dlanguage=Python3 \
    -o generated \
    InterlisLexer.g4 \
    InterlisParser.g4
```

The generated files are stored in the `generated/` directory.
This directory contains the Python sources generated by ANTLR4 and should not be edited manually.

## Cleanup

To remove the virtual environment, the ANTLR cache and the generated parser files:

`rm -rf .venv .antlr generated/`
